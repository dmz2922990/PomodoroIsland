# 任务统计信息展示 + 数据导出 实现方案

## 现状要点（已探明）

- 数据源：`TaskStore.tasks`（TaskItem 含 pomosDone/planned/createdAt/finishedAt）+ `focusLog`（`FocusEntry{date, onTime}`，保留 60 天，**未关联任务 id**），持久化 store.json（0.4s 防抖，已有旧格式迁移先例）
- 面板页面机制：`PanelPage` 枚举 + `CapsuleSegmentButton` 胶囊 Tab（同文件私有，可直接复用）；面板固定 380×492，深色主题
- 无任何图表组件、无 NSSavePanel/导出能力；**无沙盒**（NSSavePanel 可直接用）
- 项目 min macOS 13 → **Swift Charts 系统框架可用，零依赖**

## M1 数据层：番茄记录关联任务 + 统计计算（~50 行）

- `FocusEntry` 增加可选 `taskId: UUID?`（`recordFocusEnd` 已有 taskId 入参，写入即可）；解码兼容旧格式（`decodeIfPresent` 缺省 nil），旧 store.json 无损迁移
- `TaskStore` 新增统计 API（主线程纯计算）：
  - `dailyStats(days:) -> [(date, count, onTimeCount)]`（近 N 天逐日番茄数/按时数）
  - `onTimeRate(days:)`、`todayOnTimeRate`
  - `taskRanking(limit:) -> [(title, pomosDone, planned?)]`（按 pomosDone 排序）

## M2 统计页 UI（~220 行）

- `PanelPage` 增加 `.stats`；底栏加 `chart.bar.fill` 图标按钮（齿轮左侧），与现有 IconButton 同款
- 新建 `StatsPage`（与 SettingsPage 同构：顶部胶囊 Tab + ScrollView）：
  - **概要行**：今日番茄 / 今日按时率 / 本期总计（三张小卡片，白 0.06 圆角容器，复用 mcpSection 容器样式）
  - **柱状图**：Swift Charts `BarMark`，近 7/14/30 天切换（复用 CapsuleSegmentButton），番茄数按日着色（accent 红，按时部分叠加绿色 `StackedBarMark`），深色主题适配（chartXAxis 每隔 N 天显示、前景色 textSecondary）
  - **任务排行**：Top 5 任务横向进度条（自绘：标题 + `Capsule` 进度条 + x/planned 数字），复用现有进度条写法
- 入口红点：无；页面纯展示

## M3 数据导出（~90 行）

- 统计页右上角「导出」按钮 → `NSSavePanel`（`.csv`，默认文件名 `PomodoroIsland-导出-YYYYMMDD.csv`）
- CSV 内容：UTF-8 带 BOM（Excel 直开不乱码），两个区块——
  1. 任务表：`标题,是否完成,已完成番茄,计划番茄,创建时间,完成时间`
  2. 番茄记录表：`时间,是否按时,关联任务标题`（taskId → 标题映射，无关联记 `-`）
- 导出成功后按钮短暂变 ✓（无需弹窗）

## M4 文档与验收（~30 行）

- README 加「任务统计」一句 + docs/MCP.md 无需动（不新增 MCP 工具）
- 验收清单：造数据（MCP 连发任务+模拟番茄记录）→ 图表数字与 focusLog 一致 → 导出 CSV 用 Excel/文本双开验证编码与内容 → 切换 7/14/30 天 → 内置/外接屏各看一遍布局

## 不做的事（明确排除）

- 不引第三方图表库（用系统 Swift Charts）
- 不做穿透式交互图表（点柱子下钻）——v1 纯展示
- 不改 MCP 工具集（统计仅本机 UI 使用）

规模合计约 400 行新代码、3 个文件改动（TaskStore.swift / PanelView.swift / 新 StatsPage 可并入 PanelView.swift 同文件私有风格）。
